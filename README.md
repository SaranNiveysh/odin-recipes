# 🍽️ Recipes Website

A simple and beginner-friendly recipe website built using HTML. 
It displays a list of delicious recipes, including Taco, Pasta, and Pizza, 
with images and links to individual recipe pages.

## 📌 About the Project

This website allows users to explore different recipes from a main recipes 
page. Each recipe has its own dedicated page containing an image, a list 
of ingredients, step-by-step cooking instructions, and a link to return 
to the main recipes page.

## ✨ Features

- 🏠 **Main Recipes Page:** Displays a list of available recipes.
- 🌮 **Taco Recipe:** Includes ingredients and cooking instructions.
- 🍝 **Pasta Recipe:** Includes ingredients and cooking instructions.
- 🍕 **Pizza Recipe:** Includes ingredients and cooking instructions.
- 🖼️ **Food Images:** Displays images for each recipe.
- 🔗 **Navigation:** Links connect the main page to individual recipe pages.
- 📋 **Ingredients List:** Ingredients are organized using HTML lists.
- 👨‍🍳 **Cooking Instructions:** Recipes include step-by-step preparation instructions.
- ↩️ **Back to Recipes:** Each individual recipe page provides a link to the main page.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Open `index.html` in any modern web browser.
5. Click on Taco, Pasta, or Pizza to explore the corresponding recipe.
6. Use the "Back to Recipes" link to return to the main page.
